FREE HOSTING GUIDE

Publish on GitHub Pages (Android Mobile Guide)

  1. Create Account: Sign in at github.com on your Android browser and tap + → New repository.
  2. Name Repository: Enter playfinity-games, set it to Public, and tap Create repository.
  3. Upload Files: Tap uploading an existing file and select index.html, style.css, and script.js. Commit changes.
  4. Enable Pages: Go to Settings → Pages, choose Deploy from a branch → main / (root), and tap Save. Your live gaming website will be online in 60 seconds!
